# ESP32 GPIO Standalone Examples

This directory contains standalone C source files demonstrating General Purpose Input/Output (GPIO) functionality on the ESP32 using the ESP-IDF.

## Contents
*   **`blink_led.c`**: A simple example demonstrating how to configure a GPIO pin as an output and toggle its state to blink an LED.

*Note: These are raw source files. To compile and flash them to an ESP32, you will need to place them within the `main` folder of a properly structured ESP-IDF project (see `00_IDF_Full_Project/01_GPIO`).*
