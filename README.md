# ESP32 ESP-IDF Projects

This GitHub repository contains a collection of ESP32 projects built using the official Espressif IoT Development Framework (ESP-IDF). 

## Repository Structure

*   **`00_IDF_Full_Project/`**: Contains complete, buildable ESP-IDF project structures. These are full CMake-based projects ready to be compiled and flashed using the ESP-IDF toolchain.
*   **`01_GPIO/`**: Contains standalone C source files demonstrating General Purpose Input/Output (GPIO) operations.
*   **`02_NVS/`**: Contains standalone C source files demonstrating Non-Volatile Storage (NVS) operations, such as saving and reading Wi-Fi credentials.

## Prerequisites
To build and flash the full projects, ensure you have the [ESP-IDF environment](https://docs.espressif.com/projects/esp-idf/en/latest/esp32/get-started/) installed and configured on your system.
